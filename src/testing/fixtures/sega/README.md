# PRS decode fixtures

These fixed streams were generated by Sewer56's [prs-rs](https://github.com/Sewer56/prs-rs)
2.0.3, independently of Ludared. All source content and generated fixture data
are synthetic and dedicated to the public domain under **CC0 1.0**. No game
assets or third-party source code are embedded in the fixtures.

- `empty.prs`: an empty stream and its terminator.
- `literals.prs`: each byte value from 0 to 255, in order.
- `mixed_copies.prs`: short repeated strings, interrupted alternating byte runs,
  repeated suffixes, and overlapping two-byte repetitions across maximum lengths.
- `distant_copy.prs`: 8,191 bytes of explicitly seeded xorshift32 data followed
  by a repeat of its first 256 bytes, exercising distant back references.

The generator computes expected decoded lengths and SHA-256 hashes directly
from the original content **before compression**, and checks the resulting
streams with prs-rs's decoder. The E2E tests read these fixed files and compare
Ludared's decoded artifact name, length, and hash against those expectations.
They never generate expected values using Ludared's decoder or encoder.

Regenerate from the repository root with Python 3, Cargo, and cached prs-rs
2.0.3 dependencies (already used by the project):

```sh
python3 src/testing/fixtures/sega/generate_prs.py
python3 src/testing/fixtures/sega/generate_prs.py --check
```

The generator builds a temporary standalone Rust helper with the pinned prs-rs
version in offline mode. `--check` verifies byte-for-byte reproducibility without
replacing the fixture files. It prints source and compressed hashes for review;
it does not rewrite the E2E expectations.

The existing encode goldens separately pin Ludared's compressor. We do not claim
bit-exact reproduction of prs-rs streams: the two encoders choose different parses.
